JARVIS

A local AI desktop assistant for Windows. Control your computer, search the web, interact with applications and talk to your AI — while keeping the AI running locally.

Download JARVIS View on GitHub

What JARVIS Can Do

Built to make your Windows PC easier to control.

◉

Local AI

Uses Ollama to run the AI locally on your computer instead of relying on a remote AI API.

⌕

Voice Commands

Say "Jarvis" and give commands using your microphone.

▣

Computer Control

Open applications, type text, press keys, move the mouse and interact with your desktop.

⌁

Web Search

Search the web and open websites directly from the assistant.

◌

Screen Reading

Take screenshots and use OCR to read visible text on your screen.

▤

File Tools

Find files, browse folders and interact with normal user files.

◐

David & Zira

Choose between Microsoft's David and Zira voices for JARVIS responses.

◆

Modern Interface

A futuristic desktop interface designed specifically for JARVIS.

Simple Commands

Talk naturally. JARVIS handles the rest.

YOU: Jarvis, open Chrome
JARVIS: Opening Chrome.

YOU: Search the web for today's weather
JARVIS: Searching the web.

YOU: Jarvis, open Notepad and type hello
JARVIS: Done.

Installation

Get JARVIS running on your Windows PC.

1

Download JARVIS

Download the latest Windows installer from the GitHub Releases page.

2

Install JARVIS

Run the installer and follow the setup instructions.

3

Install Ollama

JARVIS uses Ollama to run its local AI model. Install Ollama if it isn't already installed.

4

Start JARVIS

Launch JARVIS and use the graphical interface or activate it with the wake word.

Requirements

What you need to run JARVIS.

Operating System Windows 10 / Windows 11
AI Engine Ollama
AI Model llama3.2:3b
Microphone Required for voice commands
